Le cadenas qu'on referme toujours pareil

Chaque jour le propriétaire ouvre le cadenas (donc met le bon code), puis le referme en tournant les roues. Vous ne voyez que les chiffres affichés une fois fermé, et vous ne savez rien de ses habitudes. Le simulateur les tire au hasard en coulisses, puis devine le code à partir des seuls relevés.

Coulisses : ce que fait vraiment le propriétaire (vous ne le savez pas)

Codes les plus probables

Tous les codes classés selon leur probabilité d'être le bon, d'après les seuls relevés. Après « Dévoiler le code », le vrai code est surligné en vert.

Évolution jour après jour

En bleu : les chiffres qu'on voit sortir. En vert : la probabilité que chaque chiffre soit le bon.
